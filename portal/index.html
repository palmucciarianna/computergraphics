Programma Didattico del Corso

PARTE I

Sistemi Grafici & Geometria per CG

Architettura hardware delle GPU, frame buffer, pipeline programmabile, spazi affini, vettori, coordinate omogenee e trasformazioni 2D/3D.

PARTE II

Modellazione Geometrica & Curve Spline

Curve parametriche, curve interpolanti di Hermite, curve di Bézier, algoritmo di de Casteljau, B-spline e superfici di suddivisione.

PARTE III

Pipeline di Rendering: Sottosistema Geometrico & Raster

Viewing 3D, clipping, rasterizzazione, interpolazione su poligoni, Z-buffer e rimozione superfici nascoste, antialiasing.

PARTE IV

Illuminazione, Shading & Laboratori Pratici

Modelli di riflessione di Lambert e Phong, Blinn-Phong, flat vs Gouraud vs Phong shading, shader GLSL, Dear ImGui e Blender.

Laboratori di Programmazione — Versione Desktop

I codici sorgenti C++, i file CMake e le dispense dei laboratori svolti su Mac con GLFW, GLAD, GLM e ImGui. Tutti i file originali sono conservati intatti nel repository.

⚡

Integrazione con VS Code & Terminale macOS

Ogni laboratorio include il pulsante VS Code per aprire istantaneamente la cartella nel tuo editor, configurazione .vscode/launch.json (tasto F5) e script ./run.sh per compilare ed eseguire con supporto a Modalità Starter e Modalità Svolta.

Informazioni sul Progetto & Guida di Manutenzione

Dettagli architetturali del portale e istruzioni per estendere i contenuti mantenendo intatta la struttura dei file.

Architettura Tecnica

  • ▸ Zero Build Step: Puro HTML5, CSS3 moderno e Vanilla JavaScript ES6+.
  • ▸ Isolamento Totale: Tutto il portale risiede esclusivamente nella cartella portal/.
  • ▸ Conservazione Materiali: I file originali (C++, CMake, PDF) non vengono mai toccati né duplicati.
  • ▸ GitHub Pages Ready: Supporta sia l'hosting statico che il deploy automatico con GitHub Actions.

Come Aggiungere Nuovi Materiali

Per registrare una nuova slide o un laboratorio:

1. Posiziona il PDF nella cartella desiderata (es. intro/)
2. Aggiungi la voce in portal/data/materials.json
3. Per un nuovo laboratorio, aggiorna portal/data/labs.json
4. Salva e fai commit: il sito si aggiornerà istantaneamente!
