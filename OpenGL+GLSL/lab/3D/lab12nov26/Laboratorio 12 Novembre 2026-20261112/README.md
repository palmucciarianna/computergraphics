# Guida Rapida Esecuzione Progetti

Gli eseguibili sono già compilati e pronti all'uso. Eseguili posizionandoti nella rispettiva cartella:

---

### 1. Animazione 2D (Cerchio)
```bash
cd "EsempiodiAnimazionesuCerchio"
./EsempiodiAnimazionesuCerchio
```

---

### 2. Scena 3D Starter (Base)
```bash
cd "ProgettoOpengl_3d_Starter"
./ProgettoOpengl_3d_Starter
```

---

### 3. Scena 3D con Due Cubi (Auto + Manuale)
```bash
cd "ProgettoOpengl_3d_DueCubi"
./ProgettoOpengl_3d_DueCubi
```
* **Cubo manuale**: tasti `I`/`K` (avanti/dietro), `J`/`L` (sinistra/destra), `U`/`O` (su/giù) o slider ImGui.
* **Camera**: `W`/`A`/`S`/`D`/`Q`/`E`, Frecce / Mouse (orbita), Rotellina (zoom).

---

### Ricompilazione (se modifichi il codice)
Dalla cartella principale:
```bash
cmake --build build
```
